# Personal Portfolio Website

A responsive, modern personal portfolio website built with HTML5, CSS3, JavaScript, and Bootstrap. Designed to highlight key personal identity roles, leadership experience, skills, and projects.

## 🚀 Live Demo

Check out the live website here:  
**[https://adenosinesaj.github.io/Portfolio/](https://adenosinesaj.github.io/Portfolio/)**

---

## ✨ Features

* **Fully Responsive Design:** Optimized for seamless display across desktop, tablet, and mobile browsers.
* **Interactive Navigation:** Features an off-canvas slide-out sidebar menu custom-built for mobile devices.
* **Smooth Animations:** Integrated scroll-triggered entry animations (`waypoint.js`) and smooth internal page jumping.
* **Highlight Cards & Sections:** Displays personal roles, leadership responsibilities, and key achievements cleanly.
* **Interactive Components:** Features smooth tabs, auto-adjusting content height, carousel slideshows, and animated stats counters.

---

## 🛠️ Built With

* **HTML5** – Page structure and semantic markup
* **CSS3** – Custom styling, animations, and layout resets
* **JavaScript (ES6)** – Interactive DOM manipulation and UI behavior
* **jQuery** – Fast, concise JavaScript library for event handling and animations
* **Bootstrap** – Responsive grid framework
